# Component Patterns

This document contains reusable code patterns and snippets extracted from the template examples. Use these patterns to maintain consistency when building new components.

---

## Quick Reference Checklist

When building a new component, use this checklist:

- [ ] Container uses `mx-auto max-w-7xl px-6 lg:px-8`
- [ ] Section spacing follows scale: `mt-32 sm:mt-56` or `mt-32 sm:mt-40`
- [ ] Typography follows the scale (hero, section, body text)
- [ ] Buttons use primary/secondary patterns
- [ ] Icons use `size-5` or `size-6` with `text-indigo-600`
- [ ] Cards use `rounded-2xl` or `rounded-xl` with appropriate shadows
- [ ] Colors use indigo/gray palette
- [ ] Responsive classes follow breakpoint pattern (sm:, lg:, xl:)
- [ ] Accessibility attributes included (aria-hidden, sr-only where needed)

### Button Variants

#### Primary Button
```tsx
<a
  href="#"
  className="rounded-md bg-indigo-600 px-3.5 py-2.5 text-sm font-semibold text-white shadow-xs hover:bg-indigo-500 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-indigo-600"
>
  Get started
</a>
```
**When to use:** Primary CTAs, main actions

#### Secondary Link
```tsx
<a href="#" className="text-sm/6 font-semibold text-gray-900">
  Learn more <span aria-hidden="true">→</span>
</a>
```
**When to use:** Secondary actions, learn more links

#### Outline Button
```tsx
<a
  href="#"
  className="text-indigo-600 inset-ring inset-ring-indigo-200 hover:inset-ring-indigo-300 rounded-md px-3 py-2 text-sm/6 font-semibold focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-indigo-600"
>
  View details
</a>
```
**When to use:** Less prominent actions, alternative CTAs
