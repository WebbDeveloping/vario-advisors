# Design System Quick Reference

One-page quick reference guide for common design system patterns.

---

## Typography Classes

| Element | Class | Usage |
|---------|-------|-------|
| Hero Heading | `text-5xl font-semibold tracking-tight text-balance text-gray-900 sm:text-7xl` | Main page titles |
| Section Heading | `text-4xl font-semibold tracking-tight text-pretty text-gray-900 sm:text-5xl` | Major section titles |
| Section Label | `text-base/7 font-semibold text-indigo-600` | Small labels above headings |
| Large Body | `text-lg/8 text-gray-600` | Large body text |
| Standard Body | `text-base/7 text-gray-600` | Standard body text |
| Muted Text | `text-lg font-medium text-pretty text-gray-500 sm:text-xl/8` | Descriptive/muted text |
| Small Text | `text-sm/6 text-gray-600` | Small text, captions |

### Line Height Reference
- `text-base/7` = 1rem font, 1.75rem line height
- `text-sm/6` = 0.875rem font, 1.5rem line height
- `text-lg/8` = 1.125rem font, 2rem line height

---

## Spacing Scale

| Spacing | Class | Usage |
|---------|-------|-------|
| Small | `mt-8` | Between related elements |
| Standard | `mt-10` | Between sections |
| Medium | `mt-16` | Sub-sections |
| Large | `mt-20` | Between major elements |
| Extra Large | `mt-32 sm:mt-56` | Between major sections |
| Alt Large | `mt-32 sm:mt-40` | Alternative large spacing |

### Container Spacing
- Main container: `mx-auto max-w-7xl px-6 lg:px-8`
- Content width: `mx-auto max-w-2xl`
- Grid gaps: `gap-x-8 gap-y-16` (standard), `gap-x-6 gap-y-10` (tighter)

## Color Palette

| Color | Class | Usage |
|-------|-------|-------|
| Primary Action | `indigo-600` | Buttons, links, accents |
| Primary Hover | `indigo-500` | Button hover states |
| Heading Text | `gray-900` | All headings |
| Body Text | `gray-600` | Standard body text |
| Muted Text | `gray-500` | Descriptive text |
| Borders | `gray-200`, `gray-900/10`, `gray-900/15` | Borders, dividers |
| Background | `white`, `gray-50` | Light backgrounds |
| Dark Background | `gray-900` | Dark sections |
| Dark Text | `white`, `gray-300`, `gray-400` | Text on dark backgrounds |

### Brand Color Mapping
- Template uses `indigo-600` - consider mapping to brand blue `#005EB8`
- See `STYLE-GUIDELINES.md` for brand color definitions

## Button Patterns

| Type | Class | Usage |
|------|-------|-------|
| Primary | `rounded-md bg-indigo-600 px-3.5 py-2.5 text-sm font-semibold text-white shadow-xs hover:bg-indigo-500 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-indigo-600` | Main CTAs |

## Responsive Breakpoints

| Breakpoint | Prefix | Min Width | Usage |
|------------|--------|-----------|-------|
| Mobile | (none) | 0px | Default, mobile-first |
| Tablet | `sm:` | 640px | Small tablets, large phones |
| Desktop | `lg:` | 1024px | Desktop screens |
| Large | `xl:` | 1280px | Large desktop screens |

### Common Responsive Patterns
- `sm:mt-56` - Larger spacing on tablet+
- `lg:px-8` - More padding on desktop
- `sm:text-7xl` - Larger text on tablet+
- `lg:grid-cols-3` - 3 columns on desktop

## Common Class Combinations

### Container
```
mx-auto max-w-7xl px-6 lg:px-8
```

### Section Wrapper
```
mx-auto mt-32 max-w-7xl px-6 sm:mt-56 lg:px-8
```

### Centered Content
```
mx-auto max-w-2xl lg:text-center
```

### Feature Grid
```
grid max-w-xl grid-cols-1 gap-x-8 gap-y-16 lg:max-w-none lg:grid-cols-3
```

### Icon Container
```
flex size-10 items-center justify-center rounded-lg bg-indigo-600
```

### Card
```
rounded-2xl bg-white p-8 shadow-lg ring-1 ring-gray-900/5
```

### Image
```
rounded-xl shadow-2xl ring-1 ring-gray-900/10
```

## Accessibility Patterns

| Pattern | Class/Attribute | Usage |
|---------|-----------------|-------|
| Screen Reader Only | `sr-only` | Hidden labels |
| Hidden from Screen | `aria-hidden="true"` | Decorative elements |
| Focus Outline | `focus-visible:outline-2 focus-visible:outline-offset-2` | Button focus states |
| ARIA Label | `aria-label="Description"` | Navigation, buttons |

---

## Quick Checklist

When building a component:
- [ ] Container: `mx-auto max-w-7xl px-6 lg:px-8`
- [ ] Spacing: `mt-32 sm:mt-56` for major sections
- [ ] Typography: Use scale from table above
- [ ] Colors: Use indigo/gray palette
- [ ] Responsive: Add `sm:`, `lg:` breakpoints
- [ ] Accessibility: Include ARIA attributes
- [ ] Icons: Use `size-5` or `size-6`
- [ ] Buttons: Use button patterns from table
