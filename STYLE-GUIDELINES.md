# Vario Advisors - Style Guidelines

This document contains the official style rules extracted from the brand guideline. Follow these rules consistently throughout the website.

---

## Typography

### Primary Font Family
**Baskerville**
- Available weights: 400 (Regular), 500 (Medium), 600 (Semi-Bold), 700 (Bold), 800 (Extra-Bold), 900 (Black)

### Secondary Font Family
**Poppins**
- Available weights: 400 (Regular), 500 (Medium), 600 (Semi-Bold), 700 (Bold), 800 (Extra-Bold), 900 (Black)

---

## Font Usage Rules

### Headers
- **Capitalization**: Use uppercase capitalization whenever possible
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 16px

### Sub-Headers
- **Capitalization**: Use uppercase capitalization
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 12px

### Body Text
- **Capitalization**: Use sentence case
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 10px

---

## Implementation Notes

- All color values must match exactly as specified above
- Font weights should only use the specified values (400, 500, 600, 700, 800, 900)
- Text alignment should default to left-aligned unless there's a specific design reason to use center or right alignment
- Header and sub-header text should use uppercase capitalization
- Body text should use standard sentence case capitalization
