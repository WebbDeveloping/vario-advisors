## Typography Scale

The following typography classes are used consistently across all components. These patterns are extracted from the template examples and should be used for all new components.

### Hero Headings

Use for main page titles and hero sections:

```tsx
className =
  "text-5xl font-semibold tracking-tight text-balance text-gray-900 sm:text-7xl";
```

### Section Headings

Use for major section titles:

```tsx
className =
  "text-4xl font-semibold tracking-tight text-pretty text-gray-900 sm:text-5xl";
```

### Section Labels (Above Headings)

Small labels that appear above section headings:

```tsx
className = "text-base/7 font-semibold text-indigo-600";
```

### Body Text Variants

**Large Body Text:**

```tsx
className = "text-lg/8 text-gray-600";
```

**Standard Body Text:**

```tsx
className = "text-base/7 text-gray-600";
```

**Muted/Descriptive Text:**

```tsx
className = "text-lg font-medium text-pretty text-gray-500 sm:text-xl/8";
```

**Small Text:**

```tsx
className = "text-sm/6 text-gray-600";
```

### Line Height System

The `/` notation in Tailwind classes represents line height:

- `text-base/7` = base font size with 1.75rem line height
- `text-sm/6` = small font with 1.5rem line height
- `text-lg/8` = large font with 2rem line height

### Text Utilities

- `text-balance` - Use for headings to prevent orphaned words
- `text-pretty` - Use for paragraphs to improve readability
- `tracking-tight` - Standard letter spacing for headings

---

## Font Usage Rules

### Headers

- **Capitalization**: Use uppercase capitalization whenever possible
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 16px
- **Use Typography Scale**: Apply the typography scale classes above for consistency

### Sub-Headers

- **Capitalization**: Use uppercase capitalization
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 12px
- **Use Typography Scale**: Apply the typography scale classes above for consistency

### Body Text

- **Capitalization**: Use sentence case
- **Alignment**: Make text left-aligned whenever possible
- **Size**: Recommended size is 10px
- **Use Typography Scale**: Apply the typography scale classes above for consistency

---

## Layout & Container Patterns

### Main Container

Always use this container class for page-level sections:

```tsx
className = "mx-auto max-w-7xl px-6 lg:px-8";
```

### Content Width

For text-heavy sections that should be narrower:

```tsx
className = "mx-auto max-w-2xl";
```

For centered content sections:

```tsx
className = "mx-auto max-w-2xl lg:text-center";
```

### Section Spacing

**Major Sections:**

- Standard: `mt-32 sm:mt-56`
- Alternative: `mt-32 sm:mt-40`

**Sub-sections:**

- Standard: `mt-16`
- Alternative: `mt-20`

**Grid Gaps:**

- Standard: `gap-x-8 gap-y-16`
- Tighter: `gap-x-6 gap-y-10`
- Feature grids: `gap-x-8 gap-y-16 lg:gap-y-16`

### Responsive Breakpoints

Follow this breakpoint system:

- **Mobile**: Default (no prefix) - 0px+
- **Tablet**: `sm:` - 640px+
- **Desktop**: `lg:` - 1024px+
- **Large Desktop**: `xl:` - 1280px+

Always design mobile-first, then add responsive classes for larger screens.

## Component Library

This project uses **shadcn/ui** components built on **Radix UI** primitives and styled with **Tailwind CSS**.

### Available Components

Components are located in `components/ui/` and include:

- `Button` - Interactive buttons with variants (default, outline, ghost, link, etc.)
- `Dialog` - Modal dialogs and overlays
- `Sheet` - Slide-over panels (used for mobile menus)
- `DropdownMenu` - Dropdown menus and navigation
- `Tabs` - Tabbed interfaces
- `Accordion` - Collapsible content sections
- `Card` - Container components with consistent styling
- `Input`, `Label`, `Select`, `Textarea` - Form elements
- `Popover`, `Tooltip` - Contextual overlays
- `Alert`, `Badge`, `Separator` - UI elements

### Using Components

1. **Import from `@/components/ui`**:

   ```tsx
   import { Button } from "@/components/ui/button";
   import { Sheet, SheetContent, SheetTrigger } from "@/components/ui/sheet";
   ```

2. **Use Tailwind classes for styling**:

   ```tsx
   <Button className="bg-brand hover:bg-brand-dark">Click me</Button>
   ```

3. **Components are fully customizable** - since they're copied into your codebase, you can modify them directly if needed.

### Component Guidelines

- **Prefer shadcn/ui components** over custom implementations for common UI patterns
- **Use brand color tokens** when customizing components (e.g., `bg-brand`, `text-brand`)
- **Maintain accessibility** - shadcn/ui components use Radix UI primitives which are accessible by default
- **Use Tailwind utility classes** for styling - avoid inline styles or custom CSS when possible

### Color Tokens

The following Tailwind color tokens are available for use:

**Brand Colors:**

- `brand` - Primary brand blue (#005EB8)
- `brand-dark` - Darker blue for hover states (#004A94)
- `brand-soft` - Light blue (#BDDEFD)
- `brand-on` - White text on brand background
- `text-brand` - Text in brand color

**Semantic Colors (from shadcn/ui):**

- `primary` - Maps to brand blue, use for primary actions
- `secondary` - Secondary actions and backgrounds
- `muted` - Muted text and backgrounds
- `accent` - Accent colors for highlights
- `destructive` - Error/destructive actions

**Custom Colors:**

- `surface`, `surface-warm` - Background surfaces
- `text`, `text-muted` - Text colors
- `border`, `border-card`, `border-strong` - Border colors

**Template Color Patterns:**
The following colors are used consistently in template components. When building new components, use these patterns:

- **Primary Actions**: `indigo-600` (buttons, links, accents)
- **Primary Hover**: `indigo-500`
- **Text Headings**: `gray-900`
- **Body Text**: `gray-600` or `gray-700`
- **Muted Text**: `gray-500`
- **Borders**: `gray-200`, `gray-900/10`, `gray-900/15`
- **Backgrounds**: `white`, `gray-50`, `gray-900` (for dark sections)
- **Dark Section Text**: `white`, `gray-300`, `gray-400`

**Note**: The template examples use `indigo-600` for primary actions. Consider mapping this to your brand blue (`#005EB8`) in your Tailwind config for consistency with brand guidelines.

### AI-Assisted Development

When using AI tools to generate code:

- Specify: "Use shadcn/ui components from `@/components/ui`"
- Specify: "Use Tailwind classes and brand color tokens (brand, text-brand, etc.)"
- Reference this document for component usage patterns
- Components follow predictable patterns - all use Tailwind classes and the `cn()` utility for class merging
- Reference `COMPONENT-PATTERNS.md` for reusable code snippets

## Component Patterns

### Button Patterns

**Primary Button:**

```tsx
<a
  href="#"
  className="rounded-md bg-indigo-600 px-3.5 py-2.5 text-sm font-semibold text-white shadow-xs hover:bg-indigo-500 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-indigo-600"
>
  Get started
</a>
```

**When to use:** Primary CTAs, main actions

**Secondary Link:**

```tsx
<a href="#" className="text-sm/6 font-semibold text-gray-900">
  Learn more <span aria-hidden="true">→</span>
</a>
```

**When to use:** Secondary actions, learn more links

**Outline Button:**

```tsx
<a
  href="#"
  className="text-indigo-600 inset-ring inset-ring-indigo-200 hover:inset-ring-indigo-300 rounded-md px-3 py-2 text-sm/6 font-semibold"
>
  View details
</a>
```

**When to use:** Less prominent actions, alternative CTAs

## Spacing System

### Vertical Spacing Scale

Use these consistent spacing values:

- `mt-8` - Small spacing (between related elements)
- `mt-10` - Standard spacing (between sections)
- `mt-16` - Medium spacing (sub-sections)
- `mt-20` - Large spacing (between major elements)
- `mt-32 sm:mt-56` - Extra large spacing (between major sections)
- `mt-32 sm:mt-40` - Alternative large spacing

### Horizontal Spacing

- Container padding: `px-6 lg:px-8`
- Grid gaps: `gap-x-8` (standard), `gap-x-6` (tighter)
- Element spacing: `gap-x-6` (buttons, links)

### Grid Spacing

- Standard grid: `gap-x-8 gap-y-16`
- Feature grid: `gap-x-8 gap-y-16 lg:gap-y-16`
- Tighter grid: `gap-x-6 gap-y-10`

## Implementation Notes

- All color values must match exactly as specified above
- Font weights should only use the specified values (400, 500, 600, 700, 800, 900)
- Text alignment should default to left-aligned unless there's a specific design reason to use center or right alignment
- Header and sub-header text should use uppercase capitalization
- Body text should use standard sentence case capitalization
- Use shadcn/ui components for consistent, accessible UI patterns
